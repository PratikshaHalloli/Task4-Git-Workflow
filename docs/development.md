# Development Branch Documentation

## 1. Overview

The development branch is used to manage and
integrate project changes before merging them
into the main branch.

## 2. Objectives

- Manage development-related changes.
- Integrate new features.
- Test changes before merging.
- Maintain a stable main branch.

## 3. Development Activities

1. Create the dev branch from main.
2. Add development documentation.
3. Track changes using Git.
4. Commit changes with meaningful messages.
5. Push the dev branch to GitHub.
6. Merge reviewed changes using Pull Requests.

## 4. Git Commands

- git checkout -b dev
- git add .
- git commit
- git push

## 5. Conclusion

The development branch helps manage changes
separately before integrating them into main.

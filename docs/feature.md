# Feature Branch Documentation

## Feature Name

feature/add-project-info

## Objective

To demonstrate feature-based development
using Git branches.

## Activities

1. Create a separate feature branch.
2. Add project information.
3. Stage changes using git add.
4. Commit changes using git commit.
5. Push the feature branch to GitHub.
6. Create a Pull Request targeting dev.
7. Merge the Pull Request after review.

## Benefits

- Separate feature development.
- Better project organization.
- Easier collaboration.
- Controlled merging.

## Conclusion

Feature branches allow developers to work
independently before integrating changes.

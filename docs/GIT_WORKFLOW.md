# Git Workflow Documentation

## 1. Introduction

Git is a distributed version control system
used to track changes in project files.

## 2. Repository Initialization

The repository is initialized using git init.

## 3. Branch Management

Three branches are used:

- main
- dev
- feature/add-project-info

## 4. Commit Management

Git add stages changes and Git commit saves
the changes in the repository history.

## 5. Remote Repository

The local repository is connected to GitHub
using the git remote command.

## 6. Pull Request Workflow

Feature changes are merged into dev.
Development changes are merged into main.

## 7. Version Tagging

An annotated Git tag v1.0 identifies the
first project release.

## 8. Conclusion

This project demonstrates Git version control
and GitHub collaboration practices.
